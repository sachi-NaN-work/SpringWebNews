## 3. 推薦候補

| 候補区分       | 内容                                    |
|------------|---------------------------------------|
| 個人候補       | ユーザーの上位カテゴリ、上位ハッシュタグおよび探索対象から抽出するニュース |
| 全体候補       | 全ユーザーのお気に入り、Good、Bad 等の集計結果から抽出するニュース |
| 対象記事       | 有効なニュースのみ                             |
| 重複         | ニュース ID 単位で重複を除外する                    |
| 個人候補上限     | 設定された個人候補件数                           |
| 全体候補上限     | 設定された全体候補件数                           |
| カテゴリ別取得数   | 設定されたカテゴリ単位の取得件数                      |
| ハッシュタグ別取得数 | 設定されたハッシュタグ単位の取得件数                    |
| 全体走査上限     | 設定値が 0 の場合は全件を対象とする                   |

## 4. 推薦値に使用する特徴量

モデル入力は次の9項目を固定順で使用する。

| 順番 | 特徴量                   | 内容                                   |
|---:|-----------------------|--------------------------------------|
|  1 | 記事の露出                 | ニュース全体の閲覧回数を段階化した値                   |
|  2 | カテゴリ閲覧割合              | ユーザーの総閲覧数に対する対象カテゴリの閲覧割合             |
|  3 | カテゴリお気に入り割合           | ユーザーの総お気に入り数に対する対象カテゴリのお気に入り割合       |
|  4 | カテゴリ Good 割合          | ユーザーの総 Good 数に対する対象カテゴリの Good 割合     |
|  5 | カテゴリ Bad 割合           | ユーザーの総 Bad 数に対する対象カテゴリの Bad 割合       |
|  6 | 最も嗜好が強いハッシュタグの閲覧割合    | 記事に設定されたハッシュタグのうち、嗜好値が最大のハッシュタグの閲覧割合 |
|  7 | 最も嗜好が強いハッシュタグのお気に入り割合 | 嗜好値が最大のハッシュタグのお気に入り割合                |
|  8 | 最も嗜好が強いハッシュタグのGood割合  | 嗜好値が最大のハッシュタグの Good 割合               |
|  9 | 最も嗜好が強いハッシュタグのBad割合   | 嗜好値が最大のハッシュタグの Bad 割合                |

## 5. 基本評価

### 5.1 記事の露出

| 全体閲覧回数 |  露出値 |
|-------:|-----:|
|      0 | 1.00 |
|    1～5 | 0.95 |
|   6～10 | 0.85 |
|  11 以上 | 0.70 |


<br>


### 5.2 ユーザー嗜好

カテゴリまたはハッシュタグの嗜好値は、次の割合を使用して 0 以上 1 以下で算出する。

```text
嗜好値 = 0.20 × 閲覧割合
       + 0.30 × お気に入り割合
       + 0.50 × Good割合
       - 0.60 × Bad割合
```

ユーザー傾向一致度は、カテゴリ嗜好値と、記事に設定されたハッシュタグのうち最も高い嗜好値を同じ割合で反映する。

```text
ユーザー傾向一致度 = 0.50 × カテゴリ嗜好値
                 + 0.50 × 最大ハッシュタグ嗜好値
```


<br>


### 5.3 基本評価値

```text
基本評価値 = 0.35 × 記事の露出
           + 0.65 × ユーザー傾向一致度
```

## 6. 学習モデル評価

| 状態                | 評価方法                      |
|-------------------|---------------------------|
| 学習済みモデルを利用可能      | 9 特徴量を入力し、モデル評価値を取得する     |
| 学習済みモデルを利用不可      | 学習時に出力した固定係数でモデル評価値を算出する  |
| 学習済みモデルと固定係数を利用不可 | モデル評価値を 0 とし、基本評価値のみを使用する |

固定係数を使用する場合は、切片と 9 特徴量の重み付き合計でモデル評価値を算出する。

```text
モデル評価値 = 切片 + Σ（特徴量 × 対応する重み）
```

## 7. 推薦値の算出

### 7.1 補正前評価値

| 評価方法    | 算出方法           |
|---------|----------------|
| 学習済みモデル | モデル評価値 + 基本評価値 |
| 固定係数    | モデル評価値 + 基本評価値 |
| 基本評価のみ  | 基本評価値          |

<br>

### 7.2 A / B 補正

| 項目      |    値 |
|---------|-----:|
| 補正方式    |   加算 |
| A 区分補正値 | 0.00 |
| B 区分補正値 | 0.03 |

補正方式は加算または乗算を指定できる。

<br>

### 7.3 同点補正

同じ推薦値の候補間で順位を決定するため、0 以上 0.01 未満の微小値を加える。  
微小値はユーザー ID と A / B 区分を基に決定し、同一条件での変動を抑える。

<br>

### 7.4 再閲覧補正

同一ユーザーが同じニュースを繰り返し閲覧した場合は、推薦値へ次の係数を乗算する。

| ユーザー別閲覧回数 | 基本係数 |
|----------:|-----:|
|         0 | 1.00 |
|       1～5 | 0.95 |
|      6～10 | 0.70 |
|     11 以上 | 0.10 |

ユーザーの総閲覧数に対する同一記事の閲覧割合も反映する。

| 項目       |   値 |
|----------|----:|
| 閲覧割合補正係数 | 0.5 |
| 閲覧割合補正上限 | 0.2 |

<br>

### 7.5 最終推薦値

```text
最終推薦値 = （補正前評価値に A / B 補正と同点補正を適用した値）
             × 再閲覧補正係数
```

## 8. 推薦記事の選択

| 項目     | 内容                          |
|--------|-----------------------------|
| A 区分   | 全体候補 65 %、個人候補 35 % を基準とする  |
| B 区分   | 全体候補 35 %、個人候補 65 % を基準とする  |
| 全体候補枠  | 返却件数×全体候補割合を切り上げる           |
| 個人候補枠  | 返却件数から全体候補枠を差し引く            |
| カテゴリ上限 | 返却件数の 40 % を切り上げ、最低 1 件とする  |
| 件数不足時  | 未採用候補を推薦値順に追加する             |
| 上限解除   | 候補を追加しても不足する場合のみカテゴリ上限を解除する |

## 9. 推薦結果として返す情報

| 項目     | 内容                               |
|--------|----------------------------------|
| ニュース情報 | ニュース ID、カテゴリ ID、タイトル             |
| 最終推薦値  | 画面および並び順に使用する値                   |
| 評価方法   | 学習済みモデル、固定係数、基本評価のみのいずれか         |
| モデル評価値 | 学習済みモデルまたは固定係数による値               |
| 基本評価値  | 露出とユーザー傾向一致度による値                 |
| 特徴量    | 9 特徴量の値                          |
| 基本評価内訳 | 露出、カテゴリ嗜好、ハッシュタグ嗜好、ユーザー傾向一致度、各重み |
| 補正内訳   | A / B 補正、同点補正、再閲覧補正、再閲覧補正前の値     |
| 固定係数内訳 | 固定係数を使用した場合の切片と重み                |
