## 2. 共通レイアウト

### 2.1 ヘッダー

| 項目     | 表示条件  | 内容                  |
|--------|-------|---------------------|
| サイトロゴ  | ログイン後 | トップ画面へ移動する          |
| ユーザー情報 | ログイン後 | ログイン中のユーザー ID を表示する |
| マイページ  | ログイン後 | マイページへ移動する          |
| ログアウト  | ログイン後 | ログアウトしてログイン画面へ移動する  |

<br>

### 2.2 左サイドバー

| 項目      | 表示画面           | 内容                       |
|---------|----------------|--------------------------|
| カテゴリ一覧  | トップ画面、ニュース詳細画面 | 有効なカテゴリを一覧表示する           |
| お気に入り一覧 | トップ画面、ニュース詳細画面 | ユーザーがお気に入りに登録したニュースを表示する |
| 選択状態    | トップ画面、ニュース詳細画面 | 選択中のカテゴリや表示条件を分かるように表示する |

<br>

### 2.3 右サイドバー

| 項目     | 表示画面           | 内容                  |
|--------|----------------|---------------------|
| おすすめ記事 | トップ画面、ニュース詳細画面 | ユーザー向けの推薦記事を表示する    |
| 推薦スコア  | トップ画面、ニュース詳細画面 | 必要に応じて記事ごとの推薦度を表示する |

<br>

### 2.4 共通メッセージ

| 種別       | 用途                      |
|----------|-------------------------|
| 正常メッセージ  | 登録、更新、状態変更等が完了したことを通知する |
| エラーメッセージ | 入力誤り、業務上の制約、処理失敗を通知する   |
| 警告メッセージ  | 操作前に確認が必要な内容を通知する       |
| 補足メッセージ  | 入力条件、項目の意味、操作方法を説明する    |

## 3. 画面遷移

```text
ログイン画面
  └── トップ画面

トップ画面
  ├── カテゴリ別ニュース一覧
  ├── ハッシュタグ別ニュース一覧
  ├── ニュース詳細画面
  └── マイページ

ニュース詳細画面
  ├── お気に入り登録・解除
  ├── Good・Bad登録
  └── マイページ

マイページ
  ├── パスワード変更画面
  ├── ユーザー作成画面
  ├── ユーザー有効・無効画面
  ├── ユーザーロール変更画面
  ├── 推薦モデル管理画面
  ├── ニュース作成画面
  ├── カテゴリ作成画面
  ├── ニュース有効・無効画面
  ├── カテゴリ有効・無効画面
  ├── ハッシュタグ管理画面
  └── ニュース・ハッシュタグ編集画面
```

## 5. S-001 ログイン画面

### 5.1 目的

ユーザー IDとパスワードを入力し、システムへログインする。

<br>

### 5.2 入力項目

| 項目      | 必須 | 入力形式  | 内容           |
|---------|---:|-------|--------------|
| ユーザー ID |  ○ | 文字列   | 登録済みのユーザー ID |
| パスワード   |  ○ | パスワード | 登録済みのパスワード   |

<br>

### 5.3 表示項目

| 項目       | 内容                     |
|----------|------------------------|
| 画面説明     | ログイン方法を表示する            |
| 補助リンク    | 設定されたリンク名、URL、説明文を表示する |
| エラーメッセージ | 認証失敗、ロック中等の内容を表示する     |

<br>

### 5.4 操作

| 操作   | 内容                   |
|------|----------------------|
| ログイン | 入力内容を使用して認証する        |
| 認証成功 | トップ画面へ移動する           |
| 認証失敗 | ログイン画面にエラーメッセージを表示する |
| ロック中 | ログインできないことを表示する      |

## 6. S-002 トップ画面

### 6.1 目的

最新ニュース、カテゴリ別ニュース、ハッシュタグ別ニュース、おすすめ記事、お気に入り記事を表示する。

<br>

### 6.2 表示項目

| 項目      | 内容                       |
|---------|--------------------------|
| 画面タイトル  | 表示中のニュース種別に応じた名称         |
| ニュース一覧  | 最新、全件、カテゴリ別、ハッシュタグ別のニュース |
| カテゴリ一覧  | 有効なカテゴリ                  |
| お気に入り一覧 | ユーザーがお気に入りに登録したニュース      |
| おすすめ記事  | ユーザー向けの推薦記事              |
| 推薦スコア   | 必要に応じて記事ごとの推薦度           |

<br>

### 6.3 表示条件

| 条件       | 内容                        |
|----------|---------------------------|
| 初期表示     | 最新ニュースを表示する               |
| カテゴリ指定   | 指定したカテゴリのニュースを表示する        |
| 全件指定     | 公開対象のニュースを一覧表示する          |
| ハッシュタグ指定 | 指定したハッシュタグが設定されたニュースを表示する |
| A/B区分指定  | 指定した推薦方式を使用する             |

<br>

### 6.4 操作

| 操作       | 内容                   |
|----------|----------------------|
| ニュース選択   | ニュース詳細画面へ移動する        |
| カテゴリ選択   | 選択したカテゴリのニュースを表示する   |
| ハッシュタグ選択 | 選択したハッシュタグのニュースを表示する |
| おすすめ記事選択 | 選択したニュースの詳細画面へ移動する   |
| マイページ選択  | マイページへ移動する           |

## 7. S-003 ニュース詳細画面

### 7.1 目的

選択したニュースの内容を表示し、お気に入りや評価の操作を受け付ける。

<br>

### 7.2 表示項目

| 項目          | 内容                  |
|-------------|---------------------|
| タイトル        | ニュースのタイトル           |
| 本文          | ニュースの本文             |
| カテゴリ        | ニュースが属するカテゴリ        |
| 公開日時        | ニュースの公開日時           |
| ハッシュタグ      | ニュースに設定されたハッシュタグ    |
| お気に入り状態     | 登録済みか未登録か           |
| Good・Bad 状態 | ユーザーが登録した評価         |
| おすすめ記事      | ユーザー向けの推薦記事         |
| お気に入り一覧     | ユーザーがお気に入りに登録したニュース |

<br>

### 7.3 操作

| 操作       | 内容                      |
|----------|-------------------------|
| お気に入り登録  | 対象ニュースをお気に入りへ登録する       |
| お気に入り解除  | 対象ニュースをお気に入りから解除する      |
| Good 登録  | 対象ニュースを肯定的に評価する         |
| Bad 登録   | 対象ニュースを否定的に評価する         |
| 評価解除     | 登録済みの Good・Bad を解除する    |
| ハッシュタグ選択 | 同じハッシュタグが設定されたニュースを表示する |

## 8. S-004 マイページ

### 8.1 目的

ログイン中のユーザー情報と、利用可能な機能メニューを表示する。

<br>

### 8.2 表示項目

| 管理者    | すべての管理メニューを表示する            |
| 権限なし   | 対象メニューを表示しない               |

## 9. S-005 パスワード変更画面

### 9.1 目的

ログイン中のユーザーが自分のパスワードを変更する。

<br>

### 9.2 入力項目

| 項目         | 必須 | 入力条件                      |
|------------|---:|---------------------------|
| 現在のパスワード   |  ○ | 現在登録されているパスワードと一致すること     |
| 新しいパスワード   |  ○ | 8 文字以上で、英大文字、英小文字、数字を含むこと |
| 新しいパスワード確認 |  ○ | 新しいパスワードと一致すること           |

<br>

### 9.3 操作

| 操作 | 内容                  |
|----|---------------------|
| 変更 | 入力条件を確認し、パスワードを変更する |
| 戻る | マイページへ移動する          |

<br>

### 9.4 制約

| 項目          | 内容           |
|-------------|--------------|
| デモユーザー      | パスワードを変更できない |
| 現在のパスワード不一致 | エラーとする       |
| 確認値不一致      | エラーとする       |

## 10. S-006 ユーザー作成画面

### 10.1 目的

新しいユーザーを登録する。

<br>

### 10.2 入力項目

| 項目      | 必須 | 入力条件                     |
|---------|---:|--------------------------|
| ユーザー ID |  ○ | 英数字、128 文字以内、重複不可        |
| パスワード   |  ○ | 8文字以上で、英大文字、英小文字、数字を含むこと |
| パスワード確認 |  ○ | パスワードと一致すること             |
| ロール     |  ○ | 登録可能なロールから選択する           |
| 有効状態    |  ○ | 有効または無効                  |

<br>

### 10.3 選択可能なロール

| ロール      | 内容             |
|----------|----------------|
| 一般ユーザー   | 一般機能を利用する      |
| ユーザー管理者  | ユーザー管理機能を利用する  |
| 推薦モデル管理者 | 推薦モデル管理機能を利用する |
| ニュース管理者  | ニュース管理機能を利用する  |

<br>

### 10.4 操作

| 操作 | 内容                 |
|----|--------------------|
| 作成 | 入力内容を確認し、ユーザーを登録する |
| 戻る | マイページへ移動する         |

## 13. S-009 推薦モデル管理画面

## 23. 共通入力条件

| 項目     | 内容                   |
|--------|----------------------|
| 必須項目   | 未入力、空文字、空白のみを許可しない   |
| 文字数    | 項目ごとに定めた最大文字数を超えないこと |
| 選択項目   | 画面に表示された選択肢のみ受け付ける   |
| ID     | 指定された形式であること         |
| 重複不可項目 | 登録済みの値と重複しないこと       |
| パスワード  | 規定の長さと文字種を満たすこと      |
| ファイル   | 指定された形式であること         |
