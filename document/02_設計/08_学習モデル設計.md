## 2. 学習モデル概要

| 項目        | 内容                                                      |
|-----------|---------------------------------------------------------|
| 目的        | ユーザーの閲覧、お気に入り、Good、Bad の傾向から、ニュースごとのモデル評価値を算出するモデルを生成する |
| モデル形式     | ONNX 形式                                                 |
| 学習方式      | 線形回帰                                                    |
| 入力特徴量数    | 9 項目                                                    |
| A/B補正     | 学習対象に含めず、推薦値算出時に適用する                                    |

## 3. 入力特徴量

学習時と推薦時は、次の9項目を同じ順番で使用する。

| 順番 | 特徴量             | 内容                               |
|---:|-----------------|----------------------------------|
|  1 | 記事の露出           | ニュース全体の閲覧回数を段階化した値               |
|  2 | カテゴリ閲覧割合        | ユーザーの総閲覧数に対する対象カテゴリの閲覧割合         |
|  3 | カテゴリお気に入り割合     | ユーザーの総お気に入り数に対する対象カテゴリのお気に入り割合   |
|  4 | カテゴリ Good 割合    | ユーザーの総 Good 数に対する対象カテゴリの Good 割合 |
|  5 | カテゴリ Bad 割合     | ユーザーの総 Bad 数に対する対象カテゴリの Bad 割合   |
|  6 | 最大ハッシュタグ閲覧割合    | 嗜好値が最も高いハッシュタグの閲覧割合              |
|  7 | 最大ハッシュタグお気に入り割合 | 嗜好値が最も高いハッシュタグのお気に入り割合           |
|  8 | 最大ハッシュタグGood割合  | 嗜好値が最も高いハッシュタグの Good 割合          |
|  9 | 最大ハッシュタグBad割合   | 嗜好値が最も高いハッシュタグの Bad 割合           |

## 4. 特徴量の算出条件

### 4.1 記事の露出

| 全体閲覧回数 |  露出値 |
|-------:|-----:|
|      0 | 1.00 |
|    1～5 | 0.95 |
|   6～10 | 0.85 |
|   11以上 | 0.70 |

<br>

### 4.2 カテゴリ割合

少ない操作件数で割合が過大にならないよう、総操作数に 20.0 を加えて算出する。

```text
カテゴリ割合 = 対象カテゴリの操作数 ÷ max（ユーザーの総操作数 + 20.0, 1.0）
```

<br>

### 4.3 ハッシュタグ割合

```text
ハッシュタグ割合 = 対象ハッシュタグの操作数 ÷ max（ユーザーの総操作数, 1）
```

ハッシュタグ嗜好値は次の式で 0 以上 1 以下に補正する。

```text
ハッシュタグ嗜好値 = 0.20 × 閲覧割合
                   + 0.30 × お気に入り割合
                   + 0.50 × Good割合
                   - 0.60 × Bad割合
```

記事に設定された有効なハッシュタグのうち、嗜好値が最大のハッシュタグの 4 割合を特徴量として使用する。  
ハッシュタグがない場合は 0 とする。

## 5. 学習データ

| 項目           | 内容                                        |
|--------------|-------------------------------------------|
| 入力データ        | ニュース、フィードバック、ニュースとハッシュタグの関連               |
| 操作種別と表示元     | フィードバック種別を操作種別と表示元に分けて扱い、表示元がない場合は不明として扱う |
| データ順序        | 操作日時の昇順とし、同一日時ではフィードバック ID の昇順とする         |
| 同一日時の操作      | 同一日時の操作は、当該操作を反映する前の集計値で特徴量を作成する          |
| 正例           | お気に入り登録、Good、閲覧                           |
| 負例           | Bad および設定された擬似負例                          |
| 擬似負例件数       | 正例 1 件当たりの件数を設定し、既定値は 0 とする               |
| フィードバックがない場合 | 露出情報のみを持つデータを最大 20 件作成し、学習処理を成立させる        |
| Ridge正則化係数   | 1.0                                       |
| 乱数シード        | 7                                         |
| 負例の基準重み      | 0.10                                      |

## 6. 学習用重み

### 6.1 操作種別の重み

| 操作種別    |                        重み |
|---------|--------------------------:|
| お気に入り登録 |                       1.5 |
| Good    |                       1.3 |
| 閲覧      |                       1.0 |
| Bad     | `max（0.5, 負例の基準重み × 5.0）` |

<br>

### 6.2 表示元の重み

| 表示元    |  重み |
|--------|----:|
| 推薦枠    | 1.0 |
| カテゴリ画面 | 0.6 |
| 最新ニュース | 0.4 |
| 外部流入   | 0.2 |
| 不明     | 0.3 |

<br>

### 6.3 繰り返し閲覧補正

学習データの重みには、同一ニュースの繰り返し閲覧に対する補正を適用する。

```text
学習データの重み = 操作種別の重み × 表示元の重み × 繰り返し閲覧補正
```

擬似負例を使用する場合は、負例の基準重み、表示元の重み、繰り返し閲覧補正を乗算する。

## 7. 学習結果

| 出力物                           | 内容                        |
|-------------------------------|---------------------------|
| `model/rec.onnx`              | 推薦処理で利用する学習済みモデル          |
| `model/rec_fixed_params.json` | 学習済みモデルを利用できない場合に使用する固定係数 |
| `model/rec_report.json`       | 学習件数、学習条件、出力結果等の学習レポート    |

固定係数には、9 特徴量の順番、各特徴量の重み、切片、既定評価値を保存する。

```text
モデル評価値 = 切片 + Σ（特徴量 × 対応する重み）
```

## 8. 推薦時の利用条件

| 優先順位 | 条件                                 | 利用方法                         |
|-----:|------------------------------------|------------------------------|
|    1 | 学習済みモデルが利用可能                       | 学習済みモデルでモデル評価値を算出する          |
|    2 | 学習済みモデルが利用不可または評価値を取得できず、固定係数を利用可能 | 固定係数でモデル評価値を算出する             |
|    3 | 学習済みモデルと固定係数を利用不可                  | モデル評価値を 0 とし、基本評価のみで推薦値を算出する |

## 9. モデル管理

| 操作     | 仕様                                 |
|--------|------------------------------------|
| 学習     | 学習データからモデル、固定係数、学習レポートを生成する        |
| 学習成功   | 生成が完了したモデルを利用対象へ切り替える              |
| 再読込    | 保存されているモデルと固定係数を再読み込みする            |
| アップロード | ONNX 形式のモデルを保存し、正常に読み込めた場合に利用対象とする |
| 操作結果   | 最後に実行した学習、再読込、アップロードの結果を保持する       |
| タイムアウト | 学習処理の最大待機時間を 120 秒とする              |

## 10. 学習設定

| 設定項目        | 内容                                  |
|-------------|-------------------------------------|
| 操作種別の重み     | 閲覧、お気に入り、Good、Bad を学習へ反映する重み        |
| 表示元の重み      | 推薦枠、カテゴリ画面、最新ニュース、外部流入、不明を学習へ反映する重み |
| 負例設定        | Bad と擬似負例の重みおよび正例1件当たりの擬似負例件数       |
| Ridge 正則化係数 | Ridge 回帰で使用する正則化の強さ                 |
| 乱数シード       | 学習結果の再現性を保つための値                     |
| 露出値         | 全体閲覧回数の段階ごとに使用する値                   |
| 繰り返し閲覧補正    | 同じニュースを繰り返し閲覧した影響を抑える条件             |
