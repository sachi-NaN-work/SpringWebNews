## 3. Redisデータ設計

### 3.1 お気に入り情報

| 項目   | 内容                       |
|------|--------------------------|
| 用途   | ユーザーがお気に入りに登録したニュースを管理する |
| キー形式 | `favz:{ユーザー ID}`         |
| データ型 | Sorted Set               |
| 要素   | ニュース ID                  |
| スコア  | お気に入りへ登録した日時             |
| 主な操作 | 登録、解除、件数取得、一覧取得          |

<br>

### 3.2 ログインロック情報

| 項目   | 内容                         |
|------|----------------------------|
| 用途   | ユーザーごとのログイン失敗回数とロック状態を管理する |
| 管理単位 | ユーザー ID                    |
| 保存内容 | ログイン失敗回数、ロック状態             |
| 主な操作 | 失敗回数加算、ロック判定、状態解除          |

<br>

### 3.3 ユーザー別ニュース閲覧情報

| 項目   | 内容                      |
|------|-------------------------|
| 用途   | ユーザーごとのニュース閲覧回数を管理する    |
| キー形式 | `u:news:view:{ユーザー ID}` |
| データ型 | Hash                    |
| 項目   | ニュース ID                 |
| 値    | 閲覧回数                    |

<br>

### 3.4 ユーザー別カテゴリ推薦情報

| 項目   | 内容                       |
|------|--------------------------|
| 用途   | ユーザーのカテゴリごとの操作回数を管理する    |
| キー形式 | `u:cat:{操作種別}:{ユーザー ID}` |
| データ型 | Hash                     |
| 項目   | カテゴリ ID                  |
| 値    | 操作回数                     |
| 操作種別 | 閲覧、お気に入り、Good、Bad        |

<br>

### 3.5 ユーザー別ハッシュタグ推薦情報

| 項目   | 内容                       |
|------|--------------------------|
| 用途   | ユーザーのハッシュタグごとの操作回数を管理する  |
| キー形式 | `u:tag:{操作種別}:{ユーザー ID}` |
| データ型 | Hash                     |
| 項目   | ハッシュタグ ID                |
| 値    | 操作回数                     |
| 操作種別 | 閲覧、お気に入り、Good、Bad        |

<br>

### 3.6 ユーザー別操作合計

| 項目   | 内容                         |
|------|----------------------------|
| 用途   | ユーザーごとの操作回数の合計を管理する        |
| キー形式 | `u:total:{操作種別}:{ユーザー ID}` |
| データ型 | String                     |
| 値    | 操作回数の合計                    |
| 操作種別 | 閲覧、お気に入り、Good、Bad          |

<br>

### 3.7 全体ニュース閲覧情報

| 項目   | 内容                       |
|------|--------------------------|
| 用途   | A / B 区分ごとのニュース閲覧回数を管理する |
| キー形式 | `g:news:view:{A / B 区分}` |
| データ型 | Hash                     |
| 項目   | ニュース ID                  |
| 値    | 閲覧回数                     |

<br>

### 3.8 全体カテゴリ推薦情報

| 項目   | 内容                     |
|------|------------------------|
| 用途   | 全ユーザーのカテゴリごとの操作回数を管理する |
| キー形式 | `g:cat:{操作種別}`         |
| データ型 | Hash                   |
| 項目   | カテゴリ ID                |
| 値    | 操作回数                   |
| 操作種別 | お気に入り、Good、Bad         |

<br>

### 3.9 全体ハッシュタグ推薦情報

| 項目   | 内容                       |
|------|--------------------------|
| 用途   | 全ユーザーのハッシュタグごとの操作回数を管理する |
| キー形式 | `g:tag:{操作種別}`           |
| データ型 | Hash                     |
| 項目   | ハッシュタグ ID                |
| 値    | 操作回数                     |
| 操作種別 | お気に入り、Good、Bad           |

<br>

### 3.10 全体操作合計

| 項目   | 内容                 |
|------|--------------------|
| 用途   | 全ユーザーの操作回数の合計を管理する |
| キー形式 | `g:total:{操作種別}`   |
| データ型 | String             |
| 値    | 操作回数の合計            |
| 操作種別 | お気に入り、Good、Bad     |

## 4. データ更新・保持方針

| 対象              | 更新契機                   | 保持方針                               |
|-----------------|------------------------|------------------------------------|
| お気に入り情報         | お気に入り登録・解除時            | ユーザーごとの現在のお気に入り状態として保持する           |
| ログインロック情報       | ログイン失敗時、認証成功時          | ログイン失敗回数とロック状態を保持し、認証成功時に失敗状態を解除する |
| ユーザー別ニュース閲覧情報   | ニュース閲覧時                | ユーザーごとのニュース閲覧回数として保持する             |
| ユーザー別カテゴリ推薦情報   | 閲覧、お気に入り、Good、Bad の操作時 | ユーザーごとのカテゴリ別操作回数として保持する            |
| ユーザー別ハッシュタグ推薦情報 | 閲覧、お気に入り、Good、Bad の操作時 | ユーザーごとのハッシュタグ別操作回数として保持する          |
| ユーザー別操作合計       | 閲覧、お気に入り、Good、Bad の操作時 | ユーザーごとの操作種別別合計として保持する              |
| 全体ニュース閲覧情報      | ニュース閲覧時                | A / B 区分ごとのニュース閲覧回数として保持する         |
| 全体カテゴリ推薦情報      | お気に入り、Good、Bad の操作時    | 全ユーザーのカテゴリ別操作回数として保持する             |
| 全体ハッシュタグ推薦情報    | お気に入り、Good、Bad の操作時    | 全ユーザーのハッシュタグ別操作回数として保持する           |
| 全体操作合計          | お気に入り、Good、Bad の操作時    | 全ユーザーの操作種別別合計として保持する               |
