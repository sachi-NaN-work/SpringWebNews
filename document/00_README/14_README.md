### ＜ 2 ＞ 学習する内容

SpringWebNews の学習モデルは、全利用者の閲覧、お気に入り、Good、Bad などの操作履歴を基に、記事の特徴を評価するための共通ルールを学習する仕組みです。
お気に入り、Good、閲覧は評価を上げる情報として扱い、Bad は評価を下げる情報として扱います。

各操作には重要度を表す係数を学習します。記事の閲覧、お気に入り、Good、Bad の情報を、どの程度強く反映するかを（Ridge回帰によって）学習します。  
学習結果として、記事の閲覧状況、カテゴリ傾向、ハッシュタグ傾向などの特徴を、どの程度重視して評価するかを表す係数を作成します。
