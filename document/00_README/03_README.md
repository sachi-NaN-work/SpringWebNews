### ＜ 1 ＞ 使用技術

| 技術                | 用途                          |
|-------------------|-----------------------------|
| IntelliJ          | 統合開発環境（IDE）                 |
| Java 21           | -                           |
| Spring Boot 3.5.9 | Webアプリのフレームワーク              |
| Spring WebFlux    | Webアプリ（非同期処理）               |
| Spring Security   | 認証・認可（ログインや権限）              |
| Spring Thymeleaf  | HTML画面表示（HTMLテンプレート）        |
| Spring Validation | 入力値の自動チェック                  |
| Spring Actuator   | アプリ状態の監視・管理                 |
| R2DBC PostgreSQL  | 永続データを管理するリレーショナルデータベース     |
| Redis Reactive    | キャッシュや一時データを扱う高速インメモリデータストア |
| Kafka             | イベントデータの蓄積とリアルタイム配信         |
| ONNX Runtime      | 学習済みモデルの推論実行環境              |
| Python 3.12       | モデル学習で使用                    |
