#### ＜ 2 ＞ メイン機能

* TOPページ（最新ニュース一覧）の表示機能


* ニュース一覧（全ニュース / カテゴリ別 / ハッシュタグ別）の表示機能


* ニュース内容の表示


* おすすめニュース表示


* ニュースの「お気に入り」ボタンの登録


* ニュースの「good」ボタン、「bad」ボタンの登録

#### ＜ 3 ＞ 管理機能

* パスワード変更（デモユーザーは不可）


* ユーザー管理（対応権限保持ユーザーのみ）


* ニュース管理（対応権限保持ユーザーのみ）


* 学習モデルの作成・読込（対応権限保持ユーザーのみ）
