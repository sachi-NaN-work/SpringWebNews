### ＜ 1 ＞ 使用するモデルファイル

管理画面の学習モデル操作は、主に次のファイルを使います。

- `./model/rec.onnx`
- `./model/rec_fixed_params.json`（固定係数 JSON）

> `./model/rec_fixed_params.json` は、ONNX が無い / 読み込めない場合、  
> JSONの固定値で処理（フォールバック）します。

### ＜ 2 ＞ モデルファイルの保存先

> `docker-compose.yml` で `./model:/app/model` を設定しているため、
> 学習済みモデルはホスト側（※）の `./model` フォルダ配下に保存されます。  
> （※）ホスト側 ： Docker をインストールしている元のパソコン（サーバー）側
