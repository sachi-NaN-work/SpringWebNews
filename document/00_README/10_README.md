### ＜ 1 ＞ 利用可能な操作

ログイン後の `/mypage` から、権限に応じて次の画面を利用できます。

| 操作                         | 対応ロール                                                    |
|----------------------------|----------------------------------------------------------|
| パスワード変更                    | `ADMIN` / `USER_MGR` / `MODEL_MGR` / `NEWS_MGR` / `USER` |
| ユーザー新規作成 / 有効・無効切替 / ロール変更 | `ADMIN` / `USER_MGR`                                     |
| ニュースカテゴリ作成 / 有効・無効切替       | `ADMIN` / `NEWS_MGR`                                     |
| ニュース記事作成 / 有効・無効切替         | `ADMIN` / `NEWS_MGR`                                     |
| ハッシュタグマスタ管理                | `ADMIN` / `NEWS_MGR`                                     |
| 既存ニュースのハッシュタグ編集            | `ADMIN` / `NEWS_MGR`                                     |
| 学習モデル管理                    | `ADMIN` / `MODEL_MGR` / `DEMO`                           |
