### ＜ 1 ＞ API・エンドポイント一覧

| API / エンドポイント                            | 内容                |
|------------------------------------------|-------------------|
| `GET /`                                  | トップページ（要ログイン）     |
| `GET /news/{id}`                         | 記事詳細              |
| `GET /rec`                               | おすすめ記事            |
| `GET /api/categories`                    | カテゴリ              |
| `GET /api/news/latest`                   | 最新ニュース            |
| `GET /api/news/{id}`                     | ニュース詳細            |
| `POST /feedback`                         | フィードバック（good/bad） |
| `POST /api/favorites/{newsId}/favToggle` | お気に入りボタン          |
