### ＜ 1 ＞ 前提となる環境

本Webアプリを利用するには、以下の環境が必要です。

| 項目     | 内容             |
|--------|----------------|
| OS     | Windows        |
| ネットワーク | インターネット接続      |
| 実行環境   | Docker Desktop |

> **（※）** ブラウザでCookieの保存をブロックしている場合、本Webアプリが正常に動作しない可能性があります。

### ＜ 2 ＞ Docker Desktop について

本Webアプリでは、Docker Desktopを使用して、アプリの実行に必要な複数のDockerコンテナを起動します。

主に、以下のDockerコンテナで構成されています。

| コンテナ       | 役割                | 具体例                      |
|------------|-------------------|--------------------------|
| アプリ本体      | Webアプリケーションの実行    | 画面表示、ログイン認証、ニュースの検索・閲覧など |
| PostgreSQL | データの永続的な保存        | ユーザー情報、ニュース記事、お気に入り情報など  |
| Redis      | キャッシュおよび一時データの保存  | ログイン情報や一時的に利用するデータなど     |
| Kafka      | 機能間で処理データを受け渡す仕組み | ニュース取得機能から評価機能へのデータ連携など  |
