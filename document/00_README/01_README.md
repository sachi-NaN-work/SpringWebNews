### ＜ 1 ＞ 開発目的

本システムは、転職活動において Spring を用いた Web アプリケーション開発力と、設計などの上流工程の理解を示すポートフォリオとして開発する。

また、機械学習（推薦機能の学習）のスキルを身につける目的として、ユーザーの行動傾向をもとに、おすすめのリンク先を提示できる仕組みを取り入れる。

### ＜ 2 ＞ 題材の選定理由

開発の題材には、利用者が身近に感じやすく、機能のイメージもしやすい　**『ニュースサイト』** を選定した。  
『ニュースサイト』は日常的に利用されるサービスであり、記事閲覧やおすすめ表示の流れをイメージしやすい。  
そのため、推薦機能を組み込んだポートフォリオとして適していると判断した。

（※）『EC サイト』も候補にあったが、金額表示や購入操作を含むデモサイトは利用者が操作をためらう可能性があるため、今回は対象外とした。

### ＜ 3 ＞ 開発方針

実務に近い構成のアプリケーションとして設計・実装することを目指すため、ログイン処理、Docker 等を実装・使用する。

（補足）転職活動が終了しても、実際の開発現場に参考資料として、部下にも開発の手本となるような成果物とする。
