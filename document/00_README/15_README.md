### ＜ 1 ＞ 改善したいこと

| 改善項目    | 内容                                            |
|---------|-----------------------------------------------|
| 設計書     | エラー、権限、URL、API、ログなどの定義を必要に応じて分け、変更時に更新しやすくする  |
| 推薦精度    | Good、Bad、閲覧履歴などの使い方を見直し、利用者の興味により合う推薦結果にする    |

<br>

### ＜ 2 ＞ 追加したい機能

| 分類        | 将来的に追加したい機能                                                          |
|-----------|----------------------------------------------------------------------|
| 認証・ユーザー登録 | メールアドレスを使ったユーザー登録 / 認証機能<br/>SNS ログイン機能<br/>ボット対策認証機能                |
| 権限管理      | ユーザーロールの作成 / 管理機能                                                    |
| ニュース詳細    | ニュース詳細に画像・動画を添付する機能                                                  |
| ニュース管理    | 指定キーワードを含むニュースの非表示管理機能<br/>ニュースタイトル / ニュース詳細の検索機能<br/>ニュースのサムネイル表示機能 |
| 閲覧数・ランキング | ニュース詳細の閲覧数表示<br/>全体閲覧数 / カテゴリ別閲覧数ランキング                               |
| コメント・評価管理 | コメント投稿機能<br/>コメント管理画面<br/>Good / Bad 評価管理画面                          |
| 問合せ       | 問合せフォーム画面                                                            |
| アプリ展開     | モバイル版アプリ                                                             |
