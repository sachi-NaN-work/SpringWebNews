### ＜ 1 ＞ 起動手順

#### 1. Docker Desktop を起動しておく。
> 本 WEB アプリを起動する間は、Docker Desktop を起動し続ける必要があります。


<br>


#### 2. リポジトリ直下で、環境変数（.env）ファイルを作成します。
```bash
cp .env.sample .env
```


<br>


#### 3. `.env` ファイルを開き、ポート番号など必要な設定を記載します。


<br>


#### 4. リポジトリ直下で、コンテナをビルドして起動します。
```bash
docker compose up -d --build
```
- 初回起動時に初期データ（seed）が、データベース（Postgres）へ投入されます。
> 本アプリ使用用途に応じて、初期データ（seed）の調整が可能。


#### （参考）ビルド済みの場合は、以下でも起動可能。
```bash
docker compose up -d
```


#### （参考）アプリのログを確認します。エラー調査に使用。
```bash
docker compose logs -f app
```

### ＜ 2 ＞ 停止手順

#### リポジトリ直下でコンテナを停止します。
```bash
docker compose down
```


#### （参考）全ボリューム（全データ）も削除して停止する場合
```bash
docker compose down -v
```
