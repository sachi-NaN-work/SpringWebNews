#### ＜ 1 ＞ 初期データ概要

デモアプリとして手軽に実行できるように、初期データを用意しています。

初期化 SQL は `infra/docker/postgres/init/` にあります。  
seed では次のデータが投入されます。

- カテゴリ : 5件（社会 / テクノロジー / スポーツ / エンタメ / 暮らし）
- ニュース : 500件
- ハッシュタグ : 126件
- ユーザー、ロール、権限の各種サンプルデータ

> セキュリティ上、初期ユーザーはサンプルユーザーの登録のみにしています。  
> `infra/docker/postgres/init/seed/30_users.sql`を各自作成してDBへ投入してください。

#### ＜ 2 ＞ ロールの種類

seed では次のロールデータが投入されます。

| ロール（物理名）  | ロール（論理名） |
|-----------|----------|
| ADMIN     | 管理者      |
| USER_MGR  | ユーザー管理者  |
| MODEL_MGR | 学習モデル管理者 |
| NEWS_MGR  | ニュース管理者  |
| DEMO      | デモユーザー   |
| USER      | 一般ユーザー   |
