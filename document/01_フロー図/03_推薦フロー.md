## 1. 全体概要

SpringWebNews の推薦候補作成、推薦値算出、候補選択、推薦結果返却までの処理を示す。

```mermaid
flowchart TD
    A["おすすめニュース<br/>取得処理を開始"] --> B["ログイン状態を確認"]
    B --> C{"ログイン済みか"}

    C -->|はい| D["ユーザー情報を取得"]
    C -->|いいえ| E["認証エラーを返却"]

    D --> F["取得件数と<br/>A / B 区分を決定"]
    F --> G["推薦候補を取得"]
    G --> H{"推薦候補があるか"}

    H -->|はい| I["候補ごとの特徴量を<br/>作成"]
    H -->|いいえ| J["空の推薦一覧を返却"]

    I --> K["推薦値を算出"]
    K --> L["推薦候補を選択"]
    L --> M["推薦結果を返却"]

    C ~~~ D
    I ~~~ J
```

## 2. 推薦条件決定フロー

```mermaid
flowchart TD
    A["推薦条件の<br/>決定処理を開始"] --> B["取得件数を確認"]
    B --> C{"取得件数が<br/>1 以上か"}

    C -->|はい| D["指定された取得件数を<br/>使用"]
    C -->|いいえ| E["標準の取得件数を使用"]

    D --> F["A / B 区分を確認"]
    E --> F

    F --> G{"A / B 区分が<br/>指定されているか"}

    G -->|はい| H["指定された<br/>A / B 区分を使用"]
    G -->|いいえ| I["ユーザー IDを基に<br/>A / B 区分を決定"]

    H --> J["推薦条件として<br/>まとめる"]
    I --> J

    D ~~~ E
    H ~~~ I
```

## 3. 推薦候補取得フロー

```mermaid
flowchart TD
```

## 7. 推薦値算出フロー

```mermaid
flowchart TD
    A["推薦値算出処理を<br/>開始"] --> B{"推薦モデルを<br/>利用可能か"}

    B -->|はい| C["推薦モデルで<br/>モデル評価を算出"]
    B -->|いいえ| D{"固定係数を<br/>利用可能か"}

    D -->|はい| E["固定係数で<br/>モデル評価を算出"]
    D -->|いいえ| F["モデル評価を<br/>0 として扱う"]

    C --> G["基本評価を算出"]
    E --> G
    F --> G

    G --> H{"モデル評価を<br/>使用したか"}

    H -->|はい| I["モデル評価と基本評価を<br/>合計"]
    H -->|いいえ| J["基本評価を推薦値の<br/>基準とする"]

    I --> K["A / B 補正を適用"]
    J --> K

    K --> L["同点調整を適用"]
    L --> M["再閲覧補正を適用"]
    M --> N["最終推薦値として<br/>設定"]

    C ~~~ E
    E ~~~ F
    I ~~~ J
```

## 12. 推薦エラー・代替処理フロー

```mermaid
flowchart TD
    A["推薦処理中に<br/>問題が発生"] --> B{"問題種別"}

    B -->|未ログイン| C["認証エラーを返却"]
    B -->|候補なし| D["空の推薦一覧を返却"]
    B -->|推薦モデル利用不可| E["固定係数による<br/>評価へ切り替え"]
    B -->|固定係数利用不可| F["基本評価のみへ<br/>切り替え"]
    B -->|候補ごとのモデル評価失敗| G["対象候補を<br/>代替方式で評価"]
    B -->|想定外| H["推薦処理エラーを返却"]

    E --> I["推薦処理を継続"]
    F --> I
    G --> I

    C ~~~ D
    D ~~~ E
    E ~~~ F
    F ~~~ G
    G ~~~ H
```
