## 1. 全体概要

SpringWebNews の推薦モデル学習、固定係数生成、学習結果反映までの処理を示す。

```mermaid id="c06m9a"
flowchart TD
    A["モデル管理者が<br/>学習処理を開始"] --> B["操作権限を確認"]
    B --> C{"操作権限があるか"}

    C -->|はい| D["学習対象データを<br/>取得"]
    C -->|いいえ| E["権限不足を表示"]

    D --> F["学習データを作成"]
    F --> G["推薦モデルを学習"]
    G --> H{"学習に成功したか"}

    H -->|はい| I["推薦モデル・固定係数・<br/>学習レポートを保存"]
    H -->|いいえ| J["エラー内容を記録"]

    I --> K["学習結果を<br/>管理画面に表示"]
    J --> L["学習失敗結果を<br/>管理画面に表示"]

    C ~~~ D
    I ~~~ J
    K ~~~ L
```

## 4. 特徴量作成フロー

```mermaid id="4npyf3"
flowchart TD
    A["特徴量作成処理を<br/>開始"] --> B["記事の全体閲覧数を<br/>確認"]
    B --> C["記事の露出情報を作成"]
    C --> D["ユーザーのカテゴリ別<br/>操作情報を確認"]
    D --> E["カテゴリ閲覧・お気に入り・<br/>Good・Bad 傾向を作成"]
    E --> F["記事に設定された<br/>ハッシュタグを確認"]
    F --> G{"有効なハッシュタグが<br/>あるか"}

    G -->|はい| H["ハッシュタグごとの<br/>嗜好を算出"]
    G -->|いいえ| I["ハッシュタグ傾向を<br/>0 として扱う"]

    H --> J["最も嗜好が強い<br/>ハッシュタグを選択"]
    J --> K["ハッシュタグ閲覧・<br/>お気に入り・Good・Bad<br/>傾向を作成"]
    I --> L["9 種類の特徴量を<br/>まとめる"]
    K --> L

    L --> M["特徴量を学習データへ<br/>設定"]

    H ~~~ I
```

## 9. 学習エラー処理フロー

```mermaid id="1ve8hm"
flowchart TD
    A["学習処理中に<br/>問題が発生"] --> B{"問題種別"}

    B -->|権限不足| C["権限不足を表示"]
    B -->|データ取得失敗| D["データ取得エラーを<br/>表示"]
    B -->|学習失敗| E["学習エラーを表示"]
    B -->|モデル変換失敗| F["モデル変換エラーを<br/>表示"]
    B -->|保存失敗| G["学習結果保存エラーを<br/>表示"]
    B -->|再読込失敗| H["モデル再読込エラーを<br/>表示"]
    B -->|タイムアウト| I["学習タイムアウトを<br/>表示"]

    C --> J["エラー内容を記録"]
    D --> J
    E --> J
    F --> J
    G --> J
    H --> J
    I --> J

    J --> K["モデル管理画面に<br/>処理結果を表示"]

    C ~~~ D
    D ~~~ E
    E ~~~ F
    F ~~~ G
```
