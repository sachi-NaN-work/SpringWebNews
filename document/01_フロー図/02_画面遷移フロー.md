## 1. 画面遷移フローの全体概要

```mermaid
flowchart LR
    A["ログイン画面"] --> B["トップ画面"]

    B --> C["ニュース詳細画面"]
    C --> B

    B --> D["マイページ"]

    D --> E["パスワード変更画面"]
    D --> F["ユーザー管理画面"]
    D --> G["ニュース管理画面"]
    D --> H["カテゴリ管理画面"]
    D --> I["ハッシュタグ<br/>マスタ画面"]
    D --> J["ニュースタグ編集<br/>一覧画面"]
    D --> K["モデル管理画面"]

    J --> L["ニュースタグ<br/>編集画面"]
    L --> J

    E --> D
    F --> D
    G --> D
    H --> D
    I --> D
    J --> D
    K --> D

    B --> A
    D --> A
```

## 3. ニュース閲覧系の画面遷移フロー

```mermaid
flowchart TD
    A["トップ画面"] --> B["トップ画面<br/>（カテゴリ絞り込み）"]
    A --> C["トップ画面<br/>（ハッシュタグ絞り込み）"]
    A --> D["トップ画面<br/>（全カテゴリ表示）"]
    A --> E["トップ画面<br/>（最新ニュース表示）"]

    B --> F["ニュース詳細画面"]
    C --> F
    D --> F
    E --> F

    F --> A

    B ~~~ C
    C ~~~ D
    D ~~~ E
```
